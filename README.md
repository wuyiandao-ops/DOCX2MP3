功能說明 : 
1)使用自然語音TTS，不需要消耗Token。(繞道)
2)可以將TTS朗讀文字檔變成自然語言MP3。
3)同時可以上傳DOCX文字檔。自動轉檔。

為什麼做這個程式。解決甚麼痛點
我認識一位佛教的師父，年紀大青光眼。幾乎看不到。想要能用朗讀的方式聽經。但是操作不能太複雜。所以我想到將文字用TTS朗讀並轉存MP3。
這樣就可以用MP3撥放器讀經讀書。

嘗試使用EDGE讀TTS，無法存檔。
電子書讀TTS，不能存MP3。
遇到佛法專業名詞，都是破音字錯誤發音。

我問Gemini可否解決，他竟然說可以..。
這下子就有趣了。

技術特點
快速轉檔:極速並行引擎：採用非同步技術，同時處理多個段落，轉檔速度提升 200% 以上。
AI 智慧語氣優化：自動偵測「開端關鍵字」，動態調整語速與音調，模擬口氣，營造莊嚴層次感。
持久化校正表：內建 SQLite 資料庫，永久儲存破音字與專業術語的自定義發音規則。
檔案智慧分切打包：自動執行 3,000 字智慧斷句與編號，並提供一鍵 ZIP 下載功能。
