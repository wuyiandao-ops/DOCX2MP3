# 產品需求文件 (PRD) V1：專業 DOCX 轉存自然語言 MP3 工具

**版本：** 1.0 (正式版)  
**狀態：** 已實作  
**日期：** 2026年3月8日  

---

## 1. 產品定義
打造一個具備「高對比識別度」與「智慧朗讀語氣」的專業網頁工具，協助使用者將長篇 DOCX 文件轉換為高品質、自然流暢的 MP3 音訊檔。

### 1.1 核心價值
*   **極速轉換**：利用雲端並行技術，大幅縮短長文轉換時間。
*   **專業校正**：解決中文破音字與專業術語（如佛學、醫學）的發音錯誤。
*   **環境包容**：提供極致對比的視覺設計，確保在各種光線下都能清晰識別文字。
*   **智慧語氣**：AI 自動偵測文章開端，模擬莊嚴、自然的朗讀起伏。

---

## 2. 落地功能 (Implemented Features)

### 2.1 檔案處理模組
*   **DOCX 提取**：精確提取純文字，排除圖片與亂碼。
*   **智慧長文切分**：預設以 **3,000 字** 為基準，自動尋找最近的句點斷句，確保 Edge-TTS 合成穩定性。
*   **正則清洗**：自動過濾無效字元，僅保留經文/正文內容與標點。

### 2.2 轉換引擎 (極速版)
*   **Edge-TTS 整合**：採用 Microsoft 雲端神經網路語音，免 API Key、免付費。
*   **並行合成技術**：利用 `asyncio.Semaphore` 限制 3 個並發請求，平衡速度與防封鎖機制。
*   **區域限制**：精簡為 **TW (台灣)** 與 **CN (中國)**，並將所有語音角色全中文化。

### 2.3 智慧與提示功能
*   **🤖 AI 智慧語氣優化**：自動偵測「爾時、如是我聞、卷、品」等關鍵字，自動放慢語速 (-10%) 並調高音調 (+12Hz)。
*   **多重完成提醒**：
    -   **視覺**：畫面上方噴放氣球特效。
    -   **系統**：瀏覽器原生 `alert` 彈窗（確保最小化時也能閃爍提醒）。
    -   **通知**：作業系統層級桌面通知。

### 2.4 手動校正發音文字表
*   **持久化存儲**：使用 SQLite 資料庫，關閉網頁後規則依然存在。
*   **預載詞庫**：內建常用佛學專業詞彙（如：般若 -> 波惹）。

## 3. 使用者介面設計 (UX/UI)

### 3.1 視覺風格：日式專業簡約風
*   **背景色**：純白色 (#FFFFFF)。
*   **標題/標籤底色**：**PANTONE 10121 C (#E8E2D6)**。
*   **核心按鈕色**：**乾燥玫瑰色 (#B05B77)**。
*   **文字反白**：深色底配純白字，白底配純黑字，確保最高對比度。

### 3.2 佈局規範
*   **720p 限制**：主介面寬度限制為 **720px** 並置中，適配各類螢幕。
*   **單頁整合**：上傳轉檔與字典管理左右/上下並列，操作不翻頁。

## 4. 成功指標
*   **穩定性**：10 萬字長文轉換成功率達 100%。
*   **速度**：1 萬字轉換時間控制在 30 秒內。
*   **易用性**：視覺識別度與操作路徑達到「一看即懂」的標準。
